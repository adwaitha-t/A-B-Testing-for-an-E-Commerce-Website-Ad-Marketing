# A/B Testing for an E-Commerce Website Ad Marketing

## 📌 Project Overview

This project compares the performance of two advertising campaigns — **Control** and **Test** — for an e-commerce website.

The objective is to evaluate **user engagement, website activity, conversion, and sales performance** and identify how each campaign can be used effectively.

## 📊 Dataset

The dataset was obtained from [Kaggle](https://www.kaggle.com/datasets/ilkeryildiz/example-dataset-for-ab-test) and submitted by **İlker Yıldız**.

> The original use case of the dataset has been modified for this e-commerce A/B testing project.

The dataset contains **30 rows and 10 columns**:

| Column              | Description                              |
| ------------------- | ---------------------------------------- |
| Campaign Name       | Name of the campaign                     |
| Date                | Date of the record                       |
| Spend [USD]         | Campaign advertising spend               |
| # of Impressions    | Number of ad impressions                 |
| Reach               | Number of unique users reached           |
| # of Website Clicks | Number of website clicks                 |
| # of Searches       | Number of website searches               |
| # of View Content   | Number of users viewing products/content |
| # of Add to Cart    | Number of users adding products to cart  |
| # of Purchase       | Number of completed purchases            |

## 📈 Final Findings

The **Control campaign** generated higher overall engagement and sales. It attracted more visitors to view products, add products to their carts, and ultimately make purchases.

However, the **Test campaign** achieved a higher conversion rate from product views and cart additions to purchases, meaning a larger proportion of engaged users completed their purchase.

## 💡 Business Recommendation

* **Control Campaign:** Better suited for marketing multiple products to a **wider audience** and generating higher overall sales.
* **Test Campaign:** Better suited for targeting a **specific audience with specific products** where purchase intent is higher.

Overall, both campaigns have different strengths and can be used strategically based on the target audience and marketing objective.
